# TMH-LPF-900 Next — 重写规格文档包

本文档包是 TMH-LPF-900(铁矿石冶金性能综合检测与控制系统,北京科技大学)的**全新重写**规格。
目标技术栈:**React + TypeScript + Vite / Rust / Tauri v2**。

## 给实施者(Claude Code)的说明

- 本包**自包含**:功能需求、字节级通讯协议、安全规则、国标公式、数据模型、验收标准全部在文档内,
  **不需要也不应该**去读旧的 Python 项目代码。旧项目仅作为历史参考,新项目**零 Python**。
- `docs/golden_vectors.json` 是用旧系统实测协议库生成的**字节级金帧测试向量**,
  是协议实现的硬验收标准(M1 里程碑),必须逐字节一致。
- 实施顺序按 `docs/10-里程碑与验收标准.md` 的 M0→M5 执行,每个里程碑有明确验收条件,
  验收不过不进入下一阶段。
- 所有安全相关规则(`docs/05-领域规范.md` §安全不变式)为**硬性要求**,任何重构不得削弱。

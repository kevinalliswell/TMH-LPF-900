# TMH-LPF-900

铁矿石冶金性能实验的离线桌面上位机，使用 React / TypeScript、Rust 和 Tauri 2。支持 GB/T 13241-2017 还原性、GB/T 13242-2017 低温粉化和 GB/T 13240-2018 自由膨胀的程序记录、数据分析与报告。

当前主线用于**桌面模拟验收**，尚未连接真实设备或完成实际国标实验。`real` / `replay` 启动会明确失败，不会使用模拟读数冒充设备数据。温控程序由仪表执行；上位机读取数据并按设备手册修改参数，实际型号的参数写入、通道映射与串口组装仍待完成。

## 已实现的功能

- 首次创建管理员、账户与角色、空闲锁定、按归属访问实验及审计；没有默认管理员口令。
- 管理员保存通讯配置，检查版本和外部文件冲突，区分已保存与当前生效值；保护确认后重启生效。坏文件明确报错，不回退覆盖。
- 三项版本化国标流程：连续恒温、气氛事务确认、固定还原/吹扫、严格冷却阈值和人工步骤；停止、故障与正常结束分别处理。
- 从国标模板派生自定义温度/气氛制度，记录修改原因、版本、条件差异和本次执行快照。首版允许编辑前三段，保留结束步骤；自定义结果单独标识。
- 原始遥测与质量码、运行终态、末批数据原子保存、失败重试和重启恢复；缺测不作为零值参与分析。
- 单次分析允许补录化学成分、称量、筛分、体积及外部操作资料，保留输入来源和分析版本。
- 同批独立试验的重复性计算、十进制修约、采用/排除原因、只追加的检验组版本和权限控制。
- 单次 HTML 报告、CSV/XLSX 数据；检验组 HTML / JSON 证据报告，可离线打印为 PDF。报告包含全过程记录核查和人工补录资料。数值重复性通过不代表全过程方法或采购性能合格。

## 安装与首次测试

候选安装包由 GitHub Actions 的 **Candidate installers** 工作流生成：Windows x64 NSIS（内含 WebView2 离线安装器）及 macOS 通用 DMG。下载包中的 `manifest.json` 和 `SHA256SUMS.txt` 标明确切源码提交与哈希；源码版本当前仍为 0.2.0，不能与已发布的旧 v0.2.0 仅按版本号混用。

候选应用使用独立名称、进程、应用标识及默认数据目录，禁用自动更新。首次启动创建账户，再按 [候选安装包验收](docs/20-候选安装包验收.md) 完成三项模拟实验、补录、检验组、报告和重启测试。候选构建没有 Windows 发布者证书或 Apple 公证；自动构建通过也不代表人工桌面或硬件验收完成。

## 本地开发

使用 Node 24、pnpm 11.10.0、Rust 1.95.0；系统还需 Tauri 对应平台构建依赖。先安装依赖，再启动桌面模拟应用：

```sh
pnpm install --frozen-lockfile
pnpm tauri dev
```

`pnpm dev` 仅提供浏览器预览。浏览器没有桌面 SQLite 和配置文件，检验组及配置保存需要使用桌面应用。需要隔离测试数据时，可设置 `TMH_DATA_DIR` 为独立绝对路径；不要指向正式数据目录。正常退出后备份整个数据目录，勿让旧版本打开已升级的数据库。

主要本地检查：

```sh
pnpm typecheck
pnpm lint
pnpm test
pnpm build
pnpm check:ipc-contract
pnpm check:tauri-security
cargo fmt --all --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
node scripts/sync-version.mjs --check
```

CI 另外执行生产依赖审计、串口骨架编译、短模拟采样与脏会话回放。协议向量验证仓库定义的字节契约，不能替代具体设备手册与实机回执验证。

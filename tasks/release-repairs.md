## 数据保存与恢复修复
- SQLite v6 在同一事务提交末批样本、终态、结束时间及幂等回执，失败整批回滚，原始提交重试不会重复采样或改写结束时间。
- 写入持久恢复文件后再提交数据库；失败时保留内存数据与文件，禁止新实验、删除记录、更新和退出。界面提供“重试保存”，成功后仍需确认保护状态。
- 启动先取得单实例资格和数据目录独占锁，再恢复日志；损坏的正式日志保留并报告，完整临时日志可以重放。没有完整末批日志的中断实验标为 recovered / data_complete=false。
- JSON 开启精确浮点往返；非数值读数和派生值溢出有质量提示，旧数值列保持可序列化。
- 关闭窗口与菜单退出共用保护/保存检查；更新期间锁定新实验与设备修改，并在安装前保持保护锁存。
- 本地测试可使用 `TMH_DATA_DIR` 指向独立目录；默认仍使用系统持久应用目录，无法确定目录时不静默写入临时目录。

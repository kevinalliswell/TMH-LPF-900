# 10 里程碑与验收标准

> 按序执行,**每个里程碑验收全过才进入下一个**。验收条目为客观可检查项。

## M0 脚手架(约数天)

产出:仓库初始化——Cargo workspace(tmh-protocols / tmh-core / src-tauri)+ Vite React TS 前端
+ pnpm + CI 全链 + CLAUDE.md(用本包模板)+ 本 docs/ 拷入仓库。

验收:
- [ ] `pnpm tauri dev` 打开空壳窗口(标题=产品名+版本,暗色);
- [ ] `cargo test --workspace`、`pnpm typecheck && pnpm lint && pnpm test` 在 CI 全绿;
- [ ] clippy `-D warnings` 通过;依赖方向检查(tmh-core 不依赖 tauri)。

## M1 协议层(tmh-protocols)

产出:三协议编解码 + CRC/校验和 + 回声跳过 + 天平判定,全部纯函数。

验收:
- [ ] `docs/golden_vectors.json` **26 条全部逐字节/逐值通过**(构帧 hex 相等,解析结果相等);
- [ ] 补充单元测试:回声跳过(纯噪声/半帧/多帧)、CPL 帧尾变体(\r\n、\r、无尾)、
      天平三分支(A00/近零/失败);随机字节输入不 panic;
- [ ] 覆盖率:protocols crate 行覆盖 ≥ 90%。

## M2 设备核心(tmh-core:总线 actor + mock/replay + 存储 + 审计)

产出:三总线 actor(轮询/健康/重连/优先级/去皮互斥)、Transport 三实现、遥测聚合、
采样管线、rusqlite 存储、审计模块、配置加载校验、`examples/soak`。

验收:
- [ ] mock 模式 soak 2 小时无 panic、无内存增长异常;
- [ ] 断线注入:5 次连续失败切离线;按 [1,2,5,10,30]s 重连;恢复后 30s 内回到在线;
- [ ] MFC:轮询进行中发 set_flow,写在下一事务边界执行(抢占验证);
- [ ] 钳制:请求 H2=8.0 → 实发 raw=500(=5.0 L/min),返回 clamped=true,审计有记录;0 放行;
      配置改坏(H2=999)时受编译期绝对上限约束;
- [ ] 去皮:mock 下成功/近零/失败三分支;去皮期间无轮询帧发出;
- [ ] 脏 replay 会话(含回声/半帧/坏校验)跑完,解析错误计数正确,无 panic;
- [ ] 采样:天平"离线"时行照写(weight=0 + 标注),1 小时行数 = 3600±1;
- [ ] 审计:关键动作逐条出现在 audit.log,格式符合 docs/06 §6.5;写失败(目录只读)不影响控制流。

## M3 应用壳 + 综合控制页(第一个可用版本)

产出:Tauri 壳(插件白名单、capability 最小化、单实例)、IPC 全套(specta 绑定)、
综合控制页(监控/控制/图表/数据表)、状态栏、开始/停止实验对话框(引擎先只做手动气氛控制)。

验收:
- [ ] mock 模式:9 温 + 重量 + 4 气 PV/SV 实时刷新(0.2s),1 小时曲线不卡(交互帧率 ≥30fps);
- [ ] 时间轴单调:图表 X 轴每帧仅推进一次(自动化断言数据数组长度一致);
- [ ] set_gas_flow 钳制提示、一键全开/全关/切断可燃气可用;
- [ ] 去皮全流程 UI(loading→结果),确认初始重量流程可用;
- [ ] 第二实例启动被拒并聚焦首实例,审计有 start_blocked;
- [ ] 断开某总线(mock 注入)→ 状态栏变红 + 对应数据置灰,恢复自动变绿。

## M4 实验引擎 + 其余页面

产出:实验引擎(状态机/程序表/推进/跳段/安全气氛)、实验采样入库、实验模式设置页、
历史查询页(列表/曲线/GB 分析/报告/导出/删除)、通讯设置页、帮助/关于页。

验收:
- [ ] 三个国标程序表逐值与 docs/05 §5.3 一致(单测断言表内容);
- [ ] 实验计时由单调时钟推进:注入每轮额外耗时后,保温时长与墙钟偏差仍 < 1%;
- [ ] mock 快进跑完 13240 全程:阶段按规则推进,采样行完整,完成后气氛=N2 5.0/其余 0(审计可查);
- [ ] 手停/引擎错误/杀进程重启三条路径都落到保护气氛(杀进程→重启时检测未完成实验并执行);
- [ ] 冷却段按新规则(T≤target+5)判达;跳段带确认与审计;
- [ ] GB 计算金值:13241(100,85,30%→50.0)、13242/13240 例题通过;分析结果写回 DB 并在详情页展示;
      13241 的 Wt 与速率指数只取还原段内的有效称量(排除天平离线占位行),无有效采样时拒绝出结果;
- [ ] 历史页:1 万行实验曲线加载 <1s(抽稀生效),UI 不冻结;删除需管理员角色 + 二次确认;
- [ ] 通讯设置:管理员角色门、实验运行中只读、保存后总线 actor 热重启生效;
      **当前未实现**(页面仍为只读展示),见 #44——M4 在此条通过前不得记为完成;
- [ ] 报告 HTML 离线可开,含条件核查与结果表;CSV/XLSX 导出可被 Excel 打开。

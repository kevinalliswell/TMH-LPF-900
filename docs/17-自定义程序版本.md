# 自定义程序版本

本项实现依据 docs/13 §5，接续国标流程修复。首版暂保留国标阶段顺序，允许修改前三段的温度、时长、升温率、容差和气氛；吹扫、人工操作与冷却末段保持基础模板。多段扩展需求等待用户确认，不假定现有单还原段分析可以正确处理多次还原。

## 保存契约

管理员且实验空闲时可保存共享程序。每次保存需要修改原因，后端生成版本、操作者与时间，重新计算相对基础国标模板的差异，不相信客户端传来的审计字段。

程序包含标准编号、标准年份、程序模板版本、基础模板完整快照、当前自定义版本与逐字段变化。新程序版本为 1；更新须提交所编辑的版本号，陈旧版本拒绝覆盖。已经发布的程序不能切换基础标准；变换基础方法应另建程序。

SQLite 原子保存当前程序及版本历史。删除共享程序不删除已经形成的版本记录和实验快照。旧程序没有经过新版校验时仅可查看，重新从当前国标复制后才可执行；不能静默改写旧结束步骤或历史记录。

## 运行契约

保存与启动均拒绝超出已配置 H₂/CO 安全上限的程序。运行初始固化程序和安全限值；程序内容与实际气氛不能依赖“下发时钳制”来消解差异。实际设备量程、温控参数寄存器和通道映射仍依赖设备资料，当前只允许模拟设备。

报告展示自定义性质、基础标准及版本、修改原因与条件差异；自定义数学指标用于研究比较，不能因继承国标模板自动声明符合国标方法。

## 已实现的接入与验证

编辑器要求填写本次修改原因，展示相对基础国标的差异，并可浏览历次版本。结束步骤与阶段类型不可编辑；升温阶段没有固定时长输入。保存、删除和启动共用生命周期锁，运行或更新期间不能修改共享程序。

气体条件校验使用当前有效 H₂/CO 上限和配置分辨率；启动重新检查，并把限值与分辨率存入实验记录。分辨率由 FLOW_SCALING / 10 得到，与现有 MFC 帧构建一致。超限或需要量化舍入的设定不能作为有效实验条件保存或执行。

还原性自定义时长使用执行快照中的唯一还原段终点。人工补录 mₜ 对应该终点，标准 180 min 的旧 m₁₈₀ 输入仍可读取，但不能用于其他终点。自定义结果记录 endpoint_min 并显示 Rₜ，不命名为 RI / R₁₈₀；原始输入与来源继续归档。

报告读取本次实验的完整程序快照，展示版本、编辑者、原因、差异及实际计算终点。旧报告不会因共享模板后续修改而变化。全过程记录核查及重复组接入分别见文档 19、18；真实设备验证仍未完成。

验证包括后端权限矩阵、来源字段伪造、旧编辑版本冲突、删除后留史、历史插入失败时整笔回滚、降低限值后的启动阻止，以及表单连续保存两版、查看历史、保护末段、60 min 自定义补录与报告转义。桌面人工验证暂被 macOS 锁屏阻挡，不能用组件测试替代已完成的原生界面验证声明。

保存前也检查基础模板是否仍为当前版本；过期模板继续可读，但更新须从当前国标另建，拒绝时不改变原记录或历史。首版吹扫段仍采用归档基础模板的目标温度，模拟执行按该快照运行；前三段温度改变不隐式改变吹扫段。

# 自定义程序版本

本项实现依据 docs/13 §5，接续国标流程修复。首版暂保留国标阶段顺序，允许修改前三段的温度、时长、升温率、容差和气氛；吹扫、人工操作与冷却末段保持基础模板。多段扩展需求等待用户确认，不假定现有单还原段分析可以正确处理多次还原。

## 保存契约

管理员且实验空闲时可保存共享程序。每次保存需要修改原因，后端生成版本、操作者与时间，重新计算相对基础国标模板的差异，不相信客户端传来的审计字段。

程序包含标准编号、标准年份、程序模板版本、基础模板完整快照、当前自定义版本与逐字段变化。新程序版本为 1；更新须提交所编辑的版本号，陈旧版本拒绝覆盖。已经发布的程序不能切换基础标准；变换基础方法应另建程序。

SQLite 原子保存当前程序及版本历史。删除共享程序不删除已经形成的版本记录和实验快照。旧程序没有经过新版校验时仅可查看，重新从当前国标复制后才可执行；不能静默改写旧结束步骤或历史记录。

## 运行契约

保存与启动均拒绝超出已配置 H₂/CO 安全上限的程序。运行初始固化程序和安全限值；程序内容与实际气氛不能依赖“下发时钳制”来消解差异。实际设备量程、温控参数寄存器和通道映射仍依赖设备资料，当前只允许模拟设备。

报告展示自定义性质、基础标准及版本、修改原因与条件差异；自定义数学指标用于研究比较，不能因继承国标模板自动声明符合国标方法。

# 03 架构设计

## 分层与依赖

`src/` 为 React 界面、手写 IPC 类型/封装和 Zustand 状态；`src-tauri/` 负责会话鉴权、命令、采样编排、恢复和 Tauri 生命周期；`tmh-core` 负责设备 actor、Transport、安全钳制、实验引擎、标准计算、存储、报告和审计；`tmh-protocols` 仅负责帧编解码。`tmh-probe` 和 soak 示例用于无头检查。

依赖方向为 `src-tauri → tmh-core → tmh-protocols`。核心禁止依赖 Tauri。软件候选版只组装 MockTransport；核心串口/回放实现与协议金帧不等于真实设备已接通，具体边界见 [协议规范](04-通讯协议规范.md)。温控程序由仪表执行，上位机不替代仪表温控闭环；仪表程序参数读写仍待型号及厂家协议接入。

## 并发与持久化

三条总线分别由专用 `std::thread` 拥有 actor 和 `Box<dyn Transport>`。每条总线串行执行阻塞事务，通过 mpsc 接收命令、watch 发布读值和新鲜度。阻塞串口不在异步运行时执行。故障重连由各总线状态机管理；没有跨线程强行中断操作系统永久阻塞调用的保证。

MFC 的紧急保护优先于普通气体操作，并在事务边界取消旧 epoch 的普通操作。全开/全关逐路等待确认，保留部分成功和失败结果，不将请求写入等同于设备确认。关闭保留上次确认的可恢复正流量；没有该值时拒绝开气。

实验引擎按单调时钟计算真实经过时间；仅 mock 可加速。采样与遥测分别采用配置间隔，采样截止时间不随普通调度抖动累计漂移。SQLite 使用互斥连接和批量事务；结束时把末批样本与终态原子提交，失败保留恢复日志及待保存状态。详见 [持久化](06-数据与持久化.md) 和 [恢复](15-数据保存与恢复.md)。

## IPC

连续遥测通过 `subscribe_telemetry` 的 Tauri Channel 发送合并快照；9路温度和4路气体采用数组，气体字段为PV/SV/开关。前端图表订阅 store，避免整个控制页随每一帧重新渲染。

实验状态以事件同步，动作与查询用 invoke。权威命令签名是 `src-tauri/src/lib.rs` 的注册列表和 `src/ipc/index.ts`；`check:ipc-contract` 核对参数名，snake_case 字段须与 Rust 一致。以下为功能索引，不是另一份独立 DTO 定义：

| 功能 | 当前入口 |
|---|---|
| 登录与账户 | get_auth_state、bootstrap_admin、login/logout、锁定/改密、用户管理 |
| 气体与天平 | set_gas_flow、set_gas_on_off、open/close_all_valves、shutoff_flammable_gases、tare_balance |
| 状态 | get_runtime_mode/settings、get_gas_safety_limits、get_device_health、get_experiment_state |
| 实验 | preflight_experiment、start/stop_experiment、skip_stage、acknowledge_stage、retry_pending_save |
| 程序 | list_programs、save/delete_custom_program、list_custom_program_revisions |
| 数据与报告 | list_experiments、get_experiment_detail/samples、三项分析、补录、导出、归属、删除、检验组预览与版本报告 |
| 通讯配置 | get_comm_config、save_comm_config、restart_for_config；保存版本/原因、管理员保护重启 |
| 更新 | get_updater_status、check_for_update、install_update；候选版禁用安装更新 |

当前命令错误返回字符串，认证等路径含稳定英文代码，部分返回中文原因；统一 `CommandError {code,message_zh,detail}` 尚未实现。历史列表当前不分页；样本查询默认最多2000点，Rust抽稀仅供图表，分析使用完整原始数据。未实现 list_serial_ports、reconnect_device、load_replay 等历史设计入口，不能照旧文档调用。

## 安全与身份边界

- MFC actor 在构帧前执行安全钳制和协议量化。H₂、CO 编译期绝对上限均为 **5.0 L/min**；配置只能降低上限。量化不能越过上限，零值关闭始终可表示。
- 异常/手动停止、退出、恢复和受控重启请求固定保护气氛 N₂=5、H₂/CO₂/CO=0，并核查确认。**正常完成按所执行程序的结束步骤处理**：RI吹扫后关闭氮气并人工取管，RDI/FSI按各自冷却/取管制度；不能把全部正常终态都写成N₂=5。
- 手动气体命令的鉴权和入队、保护复位状态发布、实验启动与重启租约共享生命周期互斥。等待设备ACK时不持有该互斥锁；旧操作回执不能覆盖新实验状态。
- 保存配置不热换总线，区分本次已生效与已保存值；重启前保护确认，详见 [配置契约](21-通讯配置保存契约.md)。
- 认证真源为Rust内存会话。受保护命令验证用户/角色，实验数据验证ADMIN或owner。锁定不停止实验，原owner或管理员登录后可接管；未登录仍可请求紧急保护，服务未启动时须明确返回未确认。
- 单机账户隔离不是数据库加密，也不保证抵御同一操作系统账户直接读取文件。
- Webview无 `updater:*`、`process:*` 等直接权限。更新和重启只能经保护、鉴权、审计入口；`check:tauri-security` 检查 capability 与 CSP。

## 单实例

single-instance 插件首先注册，第二实例通知现有窗口并记录拒绝启动。数据目录另持有生命周期独占锁，通讯配置有独立写入锁；进程退出由系统释放，禁止在运行时手工删除锁文件。真实硬件急停、断电状态及机械保护仍需设备与现场规程保障，软件模拟不能证明物理安全。

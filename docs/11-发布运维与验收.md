# 11 发布运维与验收（M5）

承接 docs/09（发布与部署）。本文是可执行的发版清单与 M5 验收单。

## 11.1 一次发版的步骤

1. `[Unreleased]` 变更归档到 CHANGELOG 的新版本节；`pnpm version <x.y.z> --no-git-tag-version`
   或手动改 `package.json` 版本（**单一来源**）。
2. `node scripts/sync-version.mjs` 同步到 `tauri.conf.json` / `index.html` / About 显示；
   `pnpm sync-version --check` 应通过（CI 也会校验）。
3. 发版 PR 合并到 `main`。
4. 打 tag：`git tag v<x.y.z> && git push origin v<x.y.z>`。
5. `Release` 工作流触发：
   - `verify-version`：tag == package.json，否则直接失败；
   - 矩阵构建 Windows（NSIS，offlineInstaller）+ macOS（.app，开发自用）；
   - `createUpdaterArtifacts` 用 minisign 私钥签出 `*.sig` 与 `latest.json`；
   - 产物进 **草稿 Release**（人工复核后再 publish）。

## 11.2 密钥与密文（Secrets）

| 用途 | 位置 | 状态 |
|---|---|---|
| Tauri updater minisign **公钥** | `tauri.conf.json > plugins.updater.pubkey` | 已内置 |
| Tauri updater minisign **私钥** | GitHub Secret `TAURI_SIGNING_PRIVATE_KEY` | **已设置**（本仓库）；本地备份见 `signing/`（gitignored），务必离线双备份 |
| 私钥口令 | workflow 内置空串（本密钥无口令） | — |
| Windows Authenticode 证书 | 需自备（Azure Trusted Signing 或 OV/EV + 云 HSM） | **待办**，见 11.4 |

> ⚠️ minisign 私钥丢失 = 所有已装机永久脱离更新通道（docs/09 §9.2）。保管人须登记。

## 11.3 更新端点（必须匿名可达）

- 运行时更新器读取 `tauri.conf.json > plugins.updater.endpoints` 的 `latest.json`。
- **本源码仓库是私有的**——私有仓库的 Release 资产对更新器 404，不能直接用作端点。
- 三选一（按 USTB 实验室网络实测）：
  1. 独立**公开** releases 仓库（如 `TMH-LPF-900-releases`），CI 把产物发布过去；
  2. **Gitee Releases**（国内可达性通常更好）；
  3. 阿里云 **OSS** 静态托管 `latest.json` + 安装包。
- 当前端点占位为方案①的公开仓库地址；改成实际托管地址后，把该仓库/OSS 的 `latest.json`
  用同一把 minisign 私钥签名（CI 已自动产出，直接搬运即可）。
- **无论更新通道是否可用，签名 NSIS 安装包 + U 盘始终是第一分发路径**（离线机现实）。

## 11.4 启用 Windows Authenticode 签名（需要证书）

`release.yml` 已预留位置。拿到证书后二选一：

- **Azure Trusted Signing**（成本最低）：在 `tauri.conf.json > bundle.windows.signCommand`
  配置 `trusted-signing-cli`，并在 workflow 注入 Azure 凭据 Secret；
- **certificateThumbprint**：把证书装进构建机证书库，配置指纹。

未配置时安装包不签名，SmartScreen 显示"未知发布者"（功能不受影响）。

## 11.5 运行时开关（现场）

| 开关 | 环境变量 | 默认 | 说明 |
|---|---|---|---|
| 更新检查 | `TMH_UPDATER=1` | 关 | 关闭时 About 显示"更新检查已关闭"，不联网 |
| 设备模式 | `TMH_DEVICE_MODE=mock` | mock | 真机接线后切真实串口传输 |
| 关闭 GPU 加速 | `TMH_DISABLE_GPU=1` | 关 | 低端工控核显渲染异常时启用（docs/09 §9.1） |

## 11.6 M5 验收清单（对应 docs/10）

- [ ] 干净 Win10（无 WebView2、无网络）VM：NSIS 一次装成，应用可跑 mock 模式；
      *（offlineInstaller 已内嵌 WebView2；需真实 VM 验证）*
- [ ] 安装包 Authenticode 签名有效、SmartScreen 无硬拦；*（需证书，见 11.4）*
- [x] 更新检查默认关闭，可配置开启；端点不可达时 About 给友好离线提示；
- [x] 更新命令走 minisign 校验（`tauri-plugin-updater` 强制，公钥内置，无法关闭）；
- [ ] 更新链路演练：发 v(N+1) 到端点 → 旧版检测到 → 校验 → 安装重启；*（需可达端点，见 11.3）*
- [x] 版本一致性：`package.json` / `tauri.conf.json` / About 三处由 `sync-version` 保证，
      tag 由 `verify-version` 校验；
- [x] 交付文档：本文 + docs/09 §9.5 现场部署规程。

## 11.7 现场部署规程（摘自 docs/09 §9.5）

- 装新版前**卸载/禁用旧 PySide6 版**（单实例插件防不了旧程序抢 COM 口）；
- 首启：改管理员口令 → 通讯设置录入现场串口/从站/限值 → 逐项测试连接转绿 →
  mock 模式培训；
- 试运行期：新旧程序**分时**跑同一实验，数据比对通过后旧版退役。

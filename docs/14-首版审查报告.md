# TMH-LPF-900 项目审查

本文保留原审查基线；后续修复状态见 [首版修复推进](../tasks/release-repairs.md)。

审查日期：2026-09-05。基准为 main **cbed665**；对照 PR #38、#39 及 #39 后续修正 #50。用户确认尚无真机连接和实际实验。本报告结论包含正式标准核对、代码路径检查、失败用例复现和本地集成验证。

**结论：现有项目有可运行的模拟实验框架，但尚不具备“按三项国标完成检验并出具可靠结果”的完整能力。** 首版可以继续做模拟流程及安装包验证；应先修正以下计算、过程判定和真实通讯问题，再进入真实实验。已有测试主要验证仓库自定公式与模拟协议，测试全绿不能证明这些规格符合标准。

**1. 对项目目标的理解**

这是离线实验室上位机：采集九路温度、四路气体流量和天平质量；按程序控制气氛、记录实验、计算指标、查询历史并输出报告。三种方法分别是还原性、低温粉化、自由膨胀。自定义实验应从已核实的国标模板派生，允许调整温度与气氛制度，并保存相对模板的变化。用户随后确认温控程序由仪表执行，上位机负责读值及修改仪表参数；硬件通讯手册仍待提供。

软件还需要表达“试样—一次试验—重复试验组—最终检验结果”这几个不同对象。当前主要只有单次实验记录。低温粉化还涉及转鼓、筛分；自由膨胀涉及体积测定；这些步骤不能仅凭炉内自动程序完成就视为完成整个检验。

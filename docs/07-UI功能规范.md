# 07 UI 功能规范(zh-CN,暗色默认)

整体布局:左侧固定侧边栏(管理员 9 项、普通用户 8 项)+ 顶部标题栏(产品名 + 版本 + 当前用户)+ 主内容区 + 底部状态栏。
底部状态栏显示三设备质量状态、数据陈旧提示、运行模式水印和遥测序号。顶部实验栏显示运行/保护/待保存状态。当前桌面仅模拟模式，浏览器预览使用浏览器模拟数据。

## P1 首页(home)

显示产品说明、T8样温、天平读数、实验状态、三设备质量和综合控制/历史/模式快捷入口。当前不提供最近五次实验列表。

## P2 综合控制(integrated control)

监控区显示T1–T9（T8为样品）、重量及四气PV/SV/开关。控制区提供各路流量设定和开关、全开/全关、可燃气切断、去皮。SV和操作反馈保留设备确认的流量分辨率，不能固定只显示一位小数；步进取当前流量换算。无已确认的可恢复流量时拒绝开气，全开部分失败逐路列出。

实时图目前为九路温度曲线，保留600个遥测点，默认约两分钟；当前未提供实时流量/重量曲线Tab或虚拟数据表。历史数据由数据库保存，不依赖此显示缓冲。

开始实验对话框填写项目、试样编号/名称、初重、备注，选择国标或自定义程序并预览阶段。当前称量用于初重默认值及差异提示；后台再次检查设备质量、数据状态、配置版本、权限及程序条件。预检未通过不能创建实验。温控制度由仪表执行，上位机记录和推进实验气氛流程。

运行状态条显示模式、当前阶段、温度条件、时长、停止/可跳段及人工确认入口。吹扫、冷却等保护结束步骤不能跳过。正常完成按程序要求等待必要的人工取管/冷却确认。

## P3 实验模式设置(experiment mode settings)

- 标准模式(3 个):只读展示阶段表(docs/05 §5.3 的表)。
- 自定义模式从三项国标模板复制，允许修改前三段的温度、容差、时长、升温率、四气流量和说明；结束步骤保持只读。
- 保存必须填写修改原因，保留基础标准/版本、条件差异、实际编辑者和不可变历史版本。配置变化后重新校验流量是否可执行；保存于SQLite，不使用独立JSON模板文件。
- 自定义制度用于研究比较，继承模板不代表符合国标方法。执行与分析使用启动时保存的程序版本。

## P4 历史查询(history query)

- 左:当前有权查看的实验列表，显示名称、类型、开始时间和完成/分析状态。当前不是服务器分页搜索接口；大量记录性能须另外验收。
- 右侧为选中实验元数据、分析/报告补录与样温/质量历史曲线；图表样本默认最多2000点，经Rust抽稀，原始分析不使用抽稀数据。
- 操作:
  - **单次分析**：13241输入亚铁W₁/全铁W₂质量百分数，缺失称量或速率数据可注明来源人工补录；标准180分钟结果为RI，自定义终点为Rₜ。13242输入还原后总质量及各筛级质量，并记录转鼓、转数、筛分时间。13240输入整份18颗试料的总体积V₀/V₁、数量、同方法确认及测量来源。
  - 保存计算及报告信息形成新版本，保留输入、来源、计算版本、操作者及时间；资料不完整须显示待补录。
  - 生成 HTML 报告(完成后可"打开文件"/"打开目录");
  - 导出 CSV/TXT/XLSX;
  - 删除实验(**管理员角色** + 二次确认,写审计;普通用户不显示该按钮)。

## P5 通讯设置(communication settings)

有效会话可读取当前配置；普通用户只读，管理员可修改。分区：
- 三路串口名称手输、波特率、数据位、校验、停止位、超时；
- 温度地址和换算、有符号格式；MFC四气地址、流量换算及H₂/CO安全上限；
- 采样、遥测刷新与陈旧判定间隔；
- 配置来源路径、当前运行值、已保存值、修改原因和待重启状态。

保存携带版本号；外部改动和旧版本拒绝覆盖。实验、待保存数据或更新期间禁止保存。保存后必须由管理员确认保护并重启整个应用才生效，期间禁止新实验；不做总线对象热替换。存储失败保留错误，重新读取可能已经替换的文件状态。浏览器预览不提供虚假的配置保存。

串口枚举、实际设备连接试读、仪表程序参数写入仍需具体型号接入，不属于当前设置页面的已实现能力。启动文件损坏时显示错误及路径，不创建设备总线，修正文件后重新打开应用。

## P6 帮助(help)

静态操作指南:实验流程、常见故障(串口占用/设备离线/去皮失败)、安全注意事项。

## P7 关于(about)

产品/版本/构建日期/单位/联系方式;**软件更新卡片**:当前版本、"检查更新"按钮
(结果:最新/发现新版 vX+更新说明+"前往下载或安装")、更新开关状态;更新检查失败给友好离线提示。

## 全局交互规范

- 所有破坏性操作(停止实验/删除/恢复默认/跳段)二次确认。
- 命令错误以toast或页面错误呈现，认证代码映射中文。当前没有统一CommandError对象，不能假定所有错误都能按同一DTO读取。
- 长任务(去皮/导出/报告/更新下载)按钮进入 loading 态,禁止重复触发。
- Esc关闭常规对话框；当前未实现F11全屏快捷键。
- 前端遥测消费:Channel → zustand store(`subscribe` 直写 ECharts,实例持 ref,不经 React state)。
## 身份与用户界面

- 首次启动显示管理员创建页，不提供默认账户或默认密码；之后进入登录页。
- 管理员创建用户时设置临时密码，目标用户首次登录必须改密。顶栏显示当前显示名和角色，并提供锁定、退出。
- `用户管理` 导航和页面仅管理员可见，切换到普通用户时不会恢复管理员表单，管理员可创建、启停、调整角色和重置临时密码；禁止当前管理员自停用/降级。
- 普通用户历史页仅展示自己的实验且不出现删除按钮；管理员查看全部数据，并可调整非运行实验的归属。
- 登录页始终提供紧急安全停机，并明确反馈设备是否确认进入保护态。

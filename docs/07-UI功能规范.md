# 07 UI 功能规范(七页,zh-CN,暗色默认)

整体布局:左侧固定侧边栏(7 项导航)+ 顶部标题栏(产品名 + 版本)+ 主内容区 + 底部状态栏。
**底部状态栏**常驻:三设备连接状态点(绿=正常/黄=陈旧/红=离线,悬停显示原因中文)、
运行模式水印(mock/replay 时黄色标签"模拟模式/回放模式")、当前实验状态摘要。

## P1 首页(home)

产品名、版本、单位徽标;三设备健康卡片;快捷入口(开始实验 → 综合控制页);最近 5 条实验记录。

## P2 综合控制(integrated control)——核心页

三栏式:
1. **监控面板**:9 路温度磁贴(T1–T9,T8 高亮标注"样品");重量磁贴(g,3 位小数);
   4 路气体卡片:**PV 大字为主,SV 小字辅助**(旧版把 SV 当 PV 显示是已修正缺陷),
   ON/OFF 状态。数据陈旧(>5s)置灰。窗口最大化时字号放大档。
2. **控制面板**:
   - 每路气体:设定值输入(数字,步进 0.1)+"设定"按钮 + ON/OFF 开关;H2/CO 显示安全上限标注,
     返回 `clamped=true` 时弹出提示"已按安全上限 X L/min 执行";
   - 一键:全开 / 全关 / **切断可燃气**(醒目红色,任何时候可用);
   - 天平:显示当前重量;"去皮"按钮(去皮中禁用,完成弹结果);"确认初始重量"按钮
     (读取稳定值 → 确认对话框 → 写入实验参数);
   - 实验:开始实验(打开参数对话框)/ 停止实验(确认对话框)/ 跳过当前阶段(确认+审计)。
3. **图表与数据区**(Tab):温度曲线(9 路,图例可点选隐藏)/ 流量曲线(4 路)/
   重量曲线 / 数据表(虚拟滚动,列=时间、时长、样温、四气 PV、重量、失重率、状态)。
   X 轴 = 实验开始起算分钟;**时间轴每帧只推进一次**;环形缓冲上限(如 4h×1Hz),超限丢最老。

**开始实验对话框**:实验模式下拉(3 标准 + 自定义列表)、样品编号/名称/重量(g)/操作员/
项目名/日期/备注(备注可空;校验规则 docs/05 §5.2);模式选中即预览阶段表。

**实验运行态**:顶部状态条显示 模式名 / 当前阶段(名称+描述)/ 目标温度±容差 / 阶段已用时长/要求时长 /
实验总时长;阶段推进 toast 提示。

## P3 实验模式设置(experiment mode settings)

- 标准模式(3 个):只读展示阶段表(docs/05 §5.3 的表)。
- 自定义模式:列表 + 新建/编辑/删除。编辑器 = 阶段列表(增删排序)+ 每阶段表单
  (阶段类型、目标温度、容差、时长、升温率、四气流量、描述);保存前校验
  (H2/CO 不超安全上限——提示,不阻断,实际执行仍会钳制;总流量>0)。存 `experiment_modes.json`。

## P4 历史查询(history query)

- 左:实验列表(**分页**,搜索名称/样品/操作员,列=名称/样品/类型/开始时间/状态);
- 右:选中实验详情(元数据 + 分析结果)+ 历史曲线(温度/重量/流量,数据经
  `get_experiment_samples(max_points≈2000)` **Rust 抽稀**后返回,加载有进度指示,不卡 UI);
- 操作:
  - **GB 分析**:按实验类型弹相应对话框——13241:输入氧含量%(默认 28.5);13242:输入四筛分质量
    (对话框实时显示总和与初始重量差);13240:输入逐球团 V0/V1;计算结果展示并写回 DB;
  - 生成 HTML 报告(完成后可"打开文件"/"打开目录");
  - 导出 CSV/TXT/XLSX;
  - 删除实验(管理员口令 + 二次确认,写审计)。

## P5 通讯设置(communication settings)

进入需管理员口令(默认 1952,首次强制改)。分区:
- 三串口参数(端口下拉=枚举 `list_serial_ports` + 手输,波特率/校验/停止位/超时);
- 温度:从站地址、scale、signed_registers;MFC:四气从站地址、FLOW_SCALING;
- **安全限值**(H2/CO 上限,红色强调,修改需再次确认);
- 采样参数(interval_s 等);
- 按钮:测试连接(逐设备试读,显示往返结果)/ 保存并应用(重启相关总线 actor)/ 恢复默认(确认)。
实验运行中整页只读并提示"实验运行中,禁止修改"。

## P6 帮助(help)

静态操作指南(Markdown 渲染):实验流程、常见故障(串口占用/设备离线/去皮失败)、安全注意事项。

## P7 关于(about)

产品/版本/构建日期/单位/联系方式;**软件更新卡片**:当前版本、"检查更新"按钮
(结果:最新/发现新版 vX+更新说明+"前往下载或安装")、更新开关状态;更新检查失败给友好离线提示。

## 全局交互规范

- 所有破坏性操作(停止实验/删除/恢复默认/跳段)二次确认。
- 命令错误按 `CommandError.code` 映射中文 toast;`PORT_IN_USE` 给专属指引("串口被其他程序占用…")。
- 长任务(去皮/导出/报告/更新下载)按钮进入 loading 态,禁止重复触发。
- 键盘:Esc 关对话框;F11 全屏。
- 前端遥测消费:Channel → zustand store(`subscribe` 直写 ECharts,实例持 ref,不经 React state)。

# 全过程记录核查

## 目的与范围

按实际执行程序的每个阶段整理采样和人工操作证据，不再仅展示还原段平均条件。这里核查的是记录是否支持各段条件，不能据软件摘要认定完成国标方法验证；测点映射、气体纯度和标态、仪器校准、制样及外部操作仍须实验室补录和复核。

## 证据规则

- 使用采样原始 JSON 的阶段编号，而非阶段名称猜测。重复出现的人工步骤分别核查；无阶段编号或编号无效的记录计为未归属，不填补缺失段。切气前的还原起始称量不作为还原气氛有效记录。
- 仅对相应设备质量标志有效且数值有限的测量统计温度、气体 PV 范围。无效占位值不参与范围；缺失采样、时间、质量码或人工操作记录须显示出来。
- 同时保留运行记录的 `data_complete` 布尔标记与 `dropped_samples` 非负整数计数。后者是采样缓冲丢弃的已知数量，不等于所有缺测数量；即使存留采样未见间隔，已知丢样仍须展示。完整标记与正丢样计数矛盾时明确提示冲突，不能按完整数据解释。
- 字段缺失、空值或类型无效时显示未知，不默认完整或零丢样。中断恢复可能只记录 `data_complete: false`，这时保留不完整状态，同时注明丢样数量未知。无法从缺失记录推断所属阶段。
- 列出各段采样数、T8 范围、四路 PV 范围、与程序不一致的 SV 次数、阶段计时和连续稳定计时。升温记录可估算相邻采样的最大升温速度，但缺失/间断采样不能证明全过程最大速度。
- 稳定段按连续稳定计时核对所需时长，不能用总停留时间替代；固定还原/吹扫按本段计时核对；冷却末点必须严格低于程序阈值；人工步骤需要本段确认、实际操作者与说明。
- 温度制度和气氛设定来自本次保存的程序快照。温度是否落入设定范围只用于相应保温条件的记录提示；升温、冷却途中不要求已经位于目标温度范围。气体 PV 列实际范围，不推测未提供的各阶段仪器允差。

## 报告与版本

单次报告加入全部阶段的记录摘要及缺项，保留既有还原段国标条件逐点核查。检验组冻结时生成并保存每次试验的全过程摘要和算法版本；旧组版本不随新算法或原始试验变化。模拟、自定义、过程记录状态以及国标方法符合性分别显示。

`PROCESS-EVIDENCE-2026-09-09.1` 增加完整性标记与已知丢样计数。旧冻结摘要缺少这两个字段时仍可读取并显示未知，保留其原算法版本，不用当前运行数据补写历史摘要。

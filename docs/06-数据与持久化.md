# 06 数据与持久化

## 6.1 数据目录

使用系统用户数据位置下的 `tmh-lpf-900`；候选构建使用独立的 `tmh-lpf-900-candidate`。`TMH_DATA_DIR` 可显式指定隔离目录。当前未实现 `portable.flag` 自动便携切换，不应依赖工作目录保存实验。进程持有数据目录独占锁。

```
config/comm_config.json       # 当前配置；TMH_COMM_CONFIG 可指定其他现存文件
config/comm_config.json.lock.sqlite # 配置写入独占锁；不要在运行时删除
data/experiments.db          # SQLite，WAL；账户、试验、模板及其版本
recovery/                   # 待提交完成记录；故障恢复前不要清理
exports/<user_id>/           # 当前操作者导出的报告和数据
logs/audit.log.YYYY-MM-DD    # 独立审计，保留180天
```

账户使用数据库中的 Argon2id 哈希，不使用 `auth.json`。自定义程序使用数据库及版本表，不使用 `experiment_modes.json`。正常关闭后备份整个数据目录；显式指定到目录外的通讯配置也须单独备份。勿用旧版本打开已升级数据库。

## 6.2 SQLite schema

当前 `PRAGMA user_version = 8`。迁移在事务中执行，拒绝比本程序支持版本更高的数据库。权威结构和迁移见 `crates/tmh-core/src/storage.rs`。

| 表 | 保存内容 |
|---|---|
| experiments | 试验、试样编号、项目、操作者快照、归属、实际时间、程序快照、运行证据与最新分析 |
| experiment_data | 时间序列及 `record_json`：各通道读值、质量、阶段及精确时间 |
| users | UUID、用户名、Argon2id PHC 哈希、角色、状态、改密要求、失败计数和时间 |
| custom_programs / custom_program_revisions | 当前自定义程序及只追加的历史版本 |
| analysis_revisions | 单次计算和人工报告补录的历史结果 |
| run_completions | 完成事务的幂等记录，防止恢复重放重复写入 |
| test_group_revisions | 每版检验组、成员原始证据、计算、报告信息和修改依据 |

v2 增加账户与归属；v3 增加试样资料和程序快照；v4 保存自定义模板；v5 保存完整采样/运行证据及分析版本；v6 增加完成幂等记录；v7 增加程序版本；v8 增加检验组版本。旧无归属实验仅管理员可见，重新分配不改写当时的操作者快照。

## 6.3 采样、缺测与恢复

| 环节 | 默认间隔 | 依据 |
|---|---|---|
| 遥测聚合到界面 | 0.2 s | PERFORMANCE_CONFIG.data_collection_interval |
| 实验采样 | 1.0 s | SAMPLING.interval_s |
| 界面陈旧判定 | 5.0 s | PERFORMANCE_CONFIG.heartbeat_timeout |
| 采样写入 | 每5条批量，终态强制提交 | 末批数据与终态在同一事务中保存 |

以上配置重启生效，并由 `get_runtime_settings` 返回当前实际值。总线轮询间隔属于协议层实现。`PERFORMANCE_CONFIG.experiment_data_interval` 是采样间隔的兼容字段，必须与 `SAMPLING.interval_s` 相等。

引擎使用单调时钟；采样保持固定截止时点，避免普通唤醒抖动累积为漏采。长停顿不补造历史样本。模拟加速会放大试验时间和样本间隔，运行证据记录实际使用的间隔。

缺测保留质量标记和时间记录，不以零值参加曲线或国标计算。RI 取本次执行程序规定终点的连续有效数据或有来源的人工补录；超过允许间隙不跨缺口插值。RVI 依据 t30 与 t60（必要时 t55/t50）的标准规则，不能用全程最小二乘替代。自定义时长标为 Rₜ，不冒用180分钟RI。

采样缓冲上限2000条；持续写失败保留待提交状态，达到上限时计数并记录丢弃，不宣称数据完整。末批采样、人工步骤和终态的恢复规则见 [数据保存与恢复](15-数据保存与恢复.md)。有待保存数据时禁止新实验、删除和重启。

## 6.4 通讯配置

沿用已有 JSON 字段：

```json
{
  "COM_RS485_TEMP": {
    "port": "COM3",
    "baudrate": 9600,
    "bytesize": 8,
    "parity": "N",
    "stopbits": 1,
    "timeout": 1.0,
    "slave_address": 0,
    "start_reg": 0,
    "reg_count": 9,
    "TEMP_CHANNELS": ["T1", "T2", "T3", "T4", "T5", "T6", "T7", "T8", "T9"],
    "scale": 0.1,
    "signed_registers": false
  },
  "COM_RS485_MFC": {
    "port": "COM4",
    "baudrate": 9600,
    "bytesize": 8,
    "parity": "E",
    "stopbits": 1,
    "timeout": 0.5
  },
  "COM_RS232_Balance": {
    "port": "COM5",
    "baudrate": 1200,
    "bytesize": 8,
    "parity": "N",
    "stopbits": 1,
    "timeout": 1.0
  },
  "SAMPLING": { "interval_s": 1.0 },
  "PERFORMANCE_CONFIG": {
    "data_collection_interval": 0.2,
    "experiment_data_interval": 1.0,
    "heartbeat_timeout": 5.0
  },
  "SLAVE_ADDRESS_MFC": { "H2": 1, "N2": 2, "CO2": 3, "CO": 4 },
  "FLOW_SCALING": { "H2": 0.1, "N2": 1.0, "CO2": 0.1, "CO": 0.1 },
  "GAS_SAFETY_LIMITS": { "H2": 5.0, "CO": 5.0 }
}
```

未显式指定配置路径时，仅首次文件不存在才创建经过校验的内置默认配置。`TMH_COMM_CONFIG` 指向的文件必须存在。解析错误、无效字段、不可读取或配置被占用均显示启动错误，且不创建设备总线；绝不静默改用默认配置。

保留历史文件缺少 `FLOW_SCALING` / `GAS_SAFETY_LIMITS` 时的字段默认值；这不是损坏文件回退。校验包括串口格式与互斥、时间范围、地址和映射、有限正系数、安全上限，以及固定氮气保护5 L/min能否准确表示。模型协议尚未核实的真实设备不能仅靠填写配置启用。

保存需要管理员、空闲且无待提交数据、当前修订号及修改原因。独占写入、原始文件冲突检查、原子替换、磁盘同步、已保存/已生效区分和受保护重启的完整契约见 [通讯配置保存契约](21-通讯配置保存契约.md)。保存成功不会热替换设备对象，重启前禁止开始新实验。重启先确认保护气氛，并再次核对磁盘配置。

## 6.5 审计日志

每行一条JSON，包含 `ts/category/action/result/operator/detail`。类别为 APP、AUTH、EXPERIMENT、GAS、BALANCE、EXPORT、CONFIG；结果为 SUCCESS、REJECTED、FAILURE。

启动、停止、保护复位、阶段请求和恢复保存补齐受理、拒绝及失败审计；命令返回错误时保留错误码和授权时操作者。启动受理在工作线程前记录；`stage_action_request`成功仅表示请求已入队，实际执行由`stage_action`另记。停止的成功表示保护回执已确认，不替代保存成功；过期的保护复位回执记REJECTED，不能虚报成功。恢复保存与启动/重启互斥。

归属、删除、三种分析和报告补录在同一生命周期边界内完成授权/对象检查/写入/审计。更新或接受关闭后拒绝新修改；SQL故障记FAILURE/STORAGE_ERROR，权限、状态和输入拒绝保留对应错误码。损坏的已有执行快照不可作为分析依据；原记录、采样和历史版本在失败后保留。

- 认证与账户操作涵盖创建首位管理员、登录/退出、锁定、改密、创建/更新用户、重置密码；权限和输入拒绝均记录，存储故障记FAILURE。
- 试验涵盖启动/停止、阶段与人工确认、终态、分析/补录、归属、删除、采样失败与恢复。
- 气体操作记录实际操作者、请求值和设备确认的应用值；全开记录每路结果和部分失败。保护复位与重启期间的手动指令入队共享生命周期互斥。
- 导出记录实际操作者和对象/版本。配置操作使用 `save_comm_config`、`restart_for_config`；文件已替换但同步失败时保留新保存状态并记FAILURE。
- 未登录保护请求记anonymous；仅进程自身动作记system。密码、哈希和临时密码不得进入日志。

审计追加写入、每条flush，GAS/EXPERIMENT额外同步磁盘。审计写失败计数，不能抛入控制流程。日志独立于调试诊断输出。

## 6.6 账户与授权

无默认账户或密码；首次启动创建管理员。密码10–128字符，连续5次登录失败锁定15分钟，期满重新计数。未知用户名仍执行等价密码校验。会话只在Rust内存，空闲默认15分钟锁定；`TMH_IDLE_TIMEOUT_S` 范围1分钟至8小时。

普通用户访问本人的试验和检验组；管理员可复核全部数据。用户管理、删除、归属调整、配置保存/重启和安装更新需要管理员。运行中的实验由其归属用户或管理员控制。临时密码用户必须先改密，锁定后重新登录。没有会话仍可请求紧急保护，界面以设备确认结果反馈。

## 6.7 报告与导出

单次报告为离线HTML；数据支持CSV、TXT、XLSX。人工补录化学成分、称量、筛分、总体积、制样/设备/校准和外部操作资料，并保留计算与补录版本。缺少资料标为待补录。

检验组导出指定冻结版本的HTML和同名JSON证据，可离线打印成PDF。报告包含程序差异、数据来源、全过程记录核查、排除原因和重复性结果。数值计算或重复性通过，不等同于全过程国标方法合格或采购性能合格。

## 3. 原始通讯记录

原始抓包保持原样另附；若需转成CSV，每帧一行，时间带UTC偏移，报文按实际字节写十六进制。不要只提供人工摘录后的“成功/失败”结论。

```csv
timestamp_iso8601,bus,device_id,direction,bytes_hex,outcome,measured_value,unit,operator_note
```

`direction` 使用 `tx` 或 `rx`；`outcome` 如手册/记录所示填写响应、异常、超时等。附上文件名、采集设备、采集软件/版本、串口参数及对应手册页码。任何写入或安全联锁验证都须引用实验室已批准的SOP；本模板不规定现场操作步骤。

## 5. 新旧系统同批样品对照

每次独立实验使用唯一 `experiment_id`。保留两套系统原始导出和报告，不手动改写或只复制最终均值。原始质量、体积、阶段和排除证据按 [国标依据与验收边界](13-国标核对与首版需求.md)、[阶段程序及人工确认](16-国标阶段与人工确认.md)记录；多次试验的采用/剔除关系按 [还原分析采样统计](22-还原分析采样统计.md) 保留。

若需要汇总成表，每项指标一行，避免把不同指标或单位混在一列：

```csv
comparison_id,sample_id,sample_batch,material_type,system,experiment_id,standard_or_custom,procedure_version,started_at_iso8601,ended_at_iso8601,valid_sample_count,excluded_sample_count,exclusion_reasons,metric,result_value,unit,raw_export_path,report_path,operator,reviewer
```

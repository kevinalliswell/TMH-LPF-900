# 01 项目概述

## 产品定位

TMH-LPF-900 是北京科技大学冶金与生态工程学院研发的**铁矿石冶金性能综合检测与控制系统**桌面软件,
运行于实验室 Windows 工控机,通过串口控制/采集三类设备,执行三项中国国家标准规定的冶金性能实验,
并完成数据记录、国标指标计算与报告生成。

- **用户**:实验室操作员(日常实验)、管理员(通讯参数/安全限值配置)。
- **运行环境**:Windows 10/11 工控机或实验室 PC,**可能离线**(无互联网);串口经 USB-RS485/RS232 适配器。
- **语言**:UI 全中文(zh-CN)。

## 受控设备

| 设备 | 通道 | 总线 | 协议 |
|---|---|---|---|
| 温度控制仪表 | 9 路热电偶 T1–T9(**T8=样品温度**) | RS485 半双工 | Modbus-RTU(功能码 0x03) |
| 质量流量控制器 MFC ×4 | H2 / N2 / CO2 / CO | RS485 半双工(**共线**,4 从站) | Azbil CPL(ASCII 帧) |
| 电子天平 | 重量(g) | RS232 | 厂商 ASCII 行协议(连续吐稳定值) |

## 支持的国标实验

| 标准 | 名称 | 核心输出 |
|---|---|---|
| GB/T 13241-2017 | 铁矿石还原性测定 | 还原度 Rt(%)、还原速率指数 |
| GB/T 13242-2017 | 铁矿石低温粉化试验(静态还原后冷转鼓) | RDI+6.3 / RDI+3.15 / RDI−0.5(%) |
| GB/T 13240-2018 | 球团矿自由膨胀指数测定 | 自由膨胀指数 SI(%) |

另支持**自定义实验模式**(用户自编阶段程序:目标温度/容差/时长/升温率/气体配比)。

## 功能清单(必须全部实现)

1. **实时监控**:9 路温度、天平重量、4 路气体 PV/SV,0.2s 级刷新;设备连接健康状态。
2. **手动控制**:逐路气体流量设定(受安全钳制)、一键可燃气体全关、天平去皮、设备重连。
3. **自动实验**:选择国标/自定义模式 → 录入参数 → 引擎按阶段程序自动控制气氛并推进,
   实时曲线(温度 9 路/流量 4 路/重量)与数据表,任意退出路径切换保护气氛。
4. **数据持久化**:1Hz 实验采样入 SQLite;实验元数据管理。
5. **历史查询**:实验列表、历史曲线回放、GB 指标分析(输入氧含量/筛分质量/体积)、
   结果保存、HTML 报告生成、CSV/TXT/XLSX 导出、删除(管理员角色 + 二次确认)。
6. **通讯设置**:串口参数、从站地址、流量缩放、可燃气安全上限(仅管理员可保存，保护确认后重启生效)。
   串口枚举和设备连接试读需型号适配，尚不属于当前页面已实现能力。
7. **系统能力**:单实例保护、结构化审计日志、软件更新检查(可配置开关)、关于/帮助页。
8. **开发模式**:mock(合成数据)/ replay(回放真实串口录制)运行,UI 有非真实模式水印。

## 相较旧版的刻意改进(实现时按新规格,不复刻旧行为)

| 项 | 旧版 | 新版 |
|---|---|---|
| 冷却段判达 | 容差=0 导致永不自动判达 | 冷却段:`T ≤ target + 5°C` 即判达(见 docs/05) |
| MFC 启停 | 无 | 每路 ON/OFF、一键全开/全关(旧版 issue #31) |
| PV/SV 显示 | 混淆 | 监控页 PV 为主、SV 辅助显示(旧版 issue #37) |
| 历史查询卡顿 | 主线程加载 | 查询/抽稀在 Rust 侧,分页 + `max_points` 抽稀(旧版 issue #33) |
| 天平去皮交互 | 阻塞式回调 | 拆分为离散命令:去皮 → 读稳定值 → 确认初始重量 |
| 更新通道 | 源码仓库已公开，发布资产可匿名读取 | updater 指向本仓库公开 Releases；仍需验证桌面端升级和目标网络可达性，U 盘安装保持首选路径 |

## 非目标(明确不做)

- 不做温控仪表的程序控温参数**写入**(旧 issue #20,列入 v2 待办;本版只读温度)。
- 不做多语言(仅 zh-CN)。
- 不做云端/多机数据同步。
- 不做移动端/网页部署(仅 Windows 桌面;macOS 构建仅供开发自用)。
- 不迁移旧版历史数据库(旧 `experiments.db` 由旧程序继续可读;如需导入工具列 v2)。

# 02 技术栈与构建基线

依赖及精确版本以 `package.json`、Cargo manifest 和两份锁文件为准；不能据历史选型表认定某依赖或功能已接入。

| 层 | 当前实现 |
|---|---|
| 前端 | React 19、严格 TypeScript、Vite、pnpm、Zustand、ECharts、Tailwind CSS 4 |
| UI | 项目内组件、原生表单；当前未引入 Radix、TanStack Table/Virtual/Query 或 dayjs |
| IPC | 手写 TypeScript DTO 与 invoke 封装；参数名由 `check:ipc-contract` 检查，尚未用 tauri-specta 生成绑定 |
| 桌面 | Tauri 2；实际构建使用仓库锁定的 Rust 1.95.0，manifest 的较低 rust-version 不代表已验证该版本可构建当前依赖 |
| 核心 | serde/serde_json、thiserror、chrono、tokio 同步通道、专用阻塞总线线程 |
| 持久化 | bundled rusqlite、WAL；共享连接互斥、批量事务与完成恢复日志；没有独立数据库写入服务 |
| 账户 | Argon2id、随机盐、UUID、Rust 内存会话 |
| 导出 | 离线 HTML、CSV/TXT、rust_xlsxwriter |
| 协议与测试 | 纯帧编解码、CRC、金帧、proptest、故障注入、Vitest/Testing Library |
| 串口 | 核心 `serial` feature 提供 serialport 传输；当前桌面只组装 mock，真实串口和回放尚未组装到桌面 |
| 数据路径 | dirs 获取系统用户数据目录，支持显式 `TMH_DATA_DIR`；未实现 portable.flag 自动切换 |

当前注册插件只有 single-instance、opener、updater、process。single-instance 必须先注册。updater/process 仅供受控 Rust 命令内部使用，不向 Webview 授予直接调用权限。未注册 dialog、log、store、window-state，勿依赖它们提供路径选择或窗口记忆。

安全配置禁止前端直接访问串口、数据库、文件系统和任意 shell；参见 [架构](03-架构设计.md)。审计为核心独立文件日志，不能用控制台输出替代。

CI 使用 Node 24（`.nvmrc`）、锁定 pnpm 和 Rust 工具链，检查格式、类型、lint、单测、构建、IPC、安全配置、生产依赖审计、serial 编译及无头验收。确切门禁以 `.github/workflows/ci.yml` 为准。跨平台 CI 或安装测试未运行时须明确标注，不能用本机通过替代。

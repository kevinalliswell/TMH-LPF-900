# 02 技术栈(定案)

以下选型为**定案**,实施时不再重新评估。版本以实施时最新稳定版为准,注明处除外。

## 前端

| 项 | 选型 | 理由 / 关键约束 |
|---|---|---|
| 框架 | React 18+ + TypeScript(strict) + Vite | 生态与招聘;strict 模式,`src/` 内禁 `any` |
| 包管理 | pnpm | 快、磁盘省 |
| 状态管理 | zustand | 遥测数据走 store **订阅**(`subscribe`/selector),不进 React 渲染循环,避免 5Hz 重渲染风暴 |
| 图表 | **ECharts**(canvas) | 14 条实时曲线 + 历史曲线;中文文档利于团队维护。`appendData`/增量 setOption + 环形缓冲;若实测刷新率不足,允许将实时页换 uPlot,历史页保留 ECharts |
| 表格 | TanStack Table + TanStack Virtual | 实验数据表虚拟滚动(小时级实验上万行) |
| 请求/查询 | TanStack Query 仅用于**查询类** invoke(历史列表/详情);动作类 invoke 直接调用 | 缓存/重试语义只对查询有意义 |
| 类型安全 IPC | **tauri-specta**(specta v2) | 从 Rust 命令/事件生成 TS 绑定,前后端类型单一来源 |
| 样式 | Tailwind CSS v4 + CSS 变量主题(暗色为默认主题) | 工业面板高密度布局;保留亮/暗双主题变量 |
| 组件 | 自绘为主 + Radix UI primitives(对话框/下拉等无样式组件) | 工业 HMI 风格自定义度高,重组件库反而碍事 |
| 时间 | dayjs | 轻 |
| 测试 | vitest + @testing-library/react | 组件与 store 逻辑 |

## Rust 侧

| 项 | 选型 | 理由 / 关键约束 |
|---|---|---|
| 壳 | **Tauri v2** | 见 docs/03;最低 Rust 1.77.2 |
| 异步运行时 | tokio(multi-thread,Tauri 自带) | 只跑 IPC/定时/编排;**串口 IO 不进 tokio** |
| 串口 | **serialport** crate | 每总线一个专用阻塞线程独占端口;`available_ports()` 供设置页枚举 |
| SQLite | **rusqlite**,`features=["bundled"]` + WAL | 静态链接零 DLL(离线工控机);单写者任务 + mpsc,根治 busy 重试 |
| 序列化 | serde / serde_json | 配置、IPC DTO、审计行 |
| 错误 | thiserror(核心 crate)+ anyhow(仅二进制边缘) | 类型化错误驱动重连状态机;IPC 统一 `CommandError { code, message_zh, detail }` |
| 日志 | tracing + tracing-subscriber(EnvFilter) + tracing-appender(日滚动) | 每总线 span(`device=temp/mfc/balance`);TRACE 级 hex 帧转储;审计**独立**于日志管线 |
| CRC | crc crate(CRC-16/MODBUS)或 30 行查表实现 | 金帧测试覆盖 |
| 路径 | dirs crate;支持"便携模式"(数据在 exe 旁) | 实验室常用绿色部署 |
| 测试 | cargo test + 金帧 fixtures;proptest 可选 | `tmh-protocols` 必须 100% 金帧通过 |

## Tauri v2 插件(白名单,不加列表外插件)

| 插件 | 用途 | 备注 |
|---|---|---|
| tauri-plugin-single-instance | 单实例(串口独占) | **必须第一个注册**;回调聚焦已开窗口 + 写审计 |
| tauri-plugin-updater + tauri-plugin-process | 更新 + 安装后重启 | 默认**关闭**,配置开启;见 docs/09 |
| tauri-plugin-dialog | 原生打开/保存对话框 | 导出路径选择 |
| tauri-plugin-log | webview 控制台桥接到日志目录 | 与 tracing 输出同目录 |
| tauri-plugin-store | UI 偏好(窗口态之外的记忆项) | 设备配置**不**放这里 |
| tauri-plugin-window-state | 窗口位置/大小记忆 | |
| tauri-plugin-opener | 打开导出目录/报告文件 | |

**明确不用**:tauri-plugin-sql(持久化在 Rust 层,SQL 不进前端)、shell、http、fs(导出全在 Rust 命令内完成)、
notification、任何社区串口插件(不能把总线裸露给 JS)。UI 面对可燃气体硬件,capability 面越小越好。

## 工程工具

- CI:GitHub Actions(windows-latest 为主 + ubuntu 快速反馈);`cargo clippy -D warnings`、
  `cargo fmt --check`、`pnpm typecheck`、`pnpm lint`(eslint)、vitest、cargo test 全绿为合并条件。
- 版本单一来源:`package.json` → CI 同步 `src-tauri/tauri.conf.json` 与 About 页显示。
- 提交规范:Conventional Commits;squash 合并。

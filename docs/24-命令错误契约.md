# 24 命令错误契约

本契约补齐 #21/#82/#83 的错误边界。所有会失败的应用命令返回 `CommandResult<T>`，错误 JSON 为：

```json
{"code":"FORBIDDEN","message_zh":"当前账户无权执行此操作","detail":null}
```

`code` 用于逻辑判断，`message_zh` 用于显示；`detail` 当前保留为 null，不反射凭据或整份请求。Rust 定义在 `src-tauri/src/command_error.rs`，TypeScript 定义及运行时读取在 `src/ipc/errors.ts`。IPC 参数门禁拒绝重新引入返回裸字符串的可失败命令。

| 码 | 含义 |
|---|---|
| AUTH_REQUIRED / SESSION_EXPIRED | 需要登录/解锁 |
| AUTH_FAILED / ACCOUNT_LOCKED / ACCOUNT_DISABLED | 认证失败或账户不可用；未知用户名与错误密码使用相同响应 |
| PASSWORD_CHANGE_REQUIRED / FORBIDDEN | 先改临时密码或缺少权限 |
| INVALID_PARAMS | 输入不满足有限数、范围或必填约束 |
| INVALID_STATE | 实验未结束，或数据未保存等状态拒绝 |
| ANALYSIS_TYPE_MISMATCH | 分析方法与执行程序不符 |
| ANALYSIS_DATA_INSUFFICIENT / ANALYSIS_DATA_INVALID | 缺少连续有效称量或执行程序证据无效 |
| TEMP_OFFLINE / MFC_OFFLINE / BALANCE_OFFLINE | 启动预检发现对应设备无有效新鲜快照 |
| EXPERIMENT_RUNNING | 运行中或待保存时禁止去皮，保持同一称量基准 |
| BALANCE_BUSY | 天平去皮未获设备终态回执，不能重复去皮、启动或重启 |
| APP_CLOSING | 已确认保护并接受关闭，不能再入队普通设备控制、实验或更新 |
| 其他预检码 | 直接保留 `PreflightIssue.code`，包括保护锁存、配置待重启及待保存数据 |
| COMMAND_FAILED | 其他既有内部服务失败；中文说明保留，不允许从说明文字推导控制逻辑 |

前端统一经 IPC 的 invoke 包装读取错误，生成 `CommandFailure extends Error`，使 toast、设置页和认证页继续显示中文，同时保留 `.code` 和 `.detail`。浏览器 mock 的 Error 与 Tauri 在命令执行前的缺参/类型错误仍可读；后者属于框架契约，不冒充应用 DTO。错误 DTO 不改变认证、实验或物理控制语义。

验证包含真实 Tauri IPC 的匿名/普通用户拒绝、错误分析及删除不改数据库、既有采样限额授权回归、前端公共 IPC 的错误读取。自动测试不构成设备或现场验收。

2026-10-24 本批本机验证：macOS arm64，Node 24，Rust 1.95.0；前端79项，原生应用98项，工作区普通/candidate套件均通过。fmt、clippy、构建、IPC/安全/版本门禁、生产依赖审计、serial feature编译、dirty replay及5分钟模拟soak均通过。真实IPC测试在改动前4项失败，改动后通过；故意把命令返回值改回字符串时，IPC门禁拒绝。独立审查已修复前端错误类名泄漏到界面的显示问题。跨平台结果以PR关联CI为准。

# 还原分析采样统计

Issue #42 的统计补充用于说明 GB/T 13241 单次分析读到了哪些原始记录，不改变国标终点、速率插值或人工补录规则，也不判定试验符合国标。

## 统计范围

分析 JSON 保存 `sample_evidence`，版本为 `REDUCTION-SAMPLES-2026-09-13.1`，范围标识为 `stored_reduction_rows`。它随构造自动还原曲线的同一次遍历产生，覆盖分析时读取的全部存储记录。`valid_sample_count`、`excluded_offline_rows` 同时保存为顶层字段，以满足原 Issue 的查询约定。

“还原曲线可用称量点”表示通过现有自动曲线筛选的原始记录数量，包括还原前基准称量和还原段终点后的记录。它不表示实际决定终点或速率的点数：程序终点限制仍由原计算逻辑执行，终点后的有效记录可以提供终点插值边界，但终点后的速率阈值不能影响结果。

## 字段与互斥原因

| 字段 | 含义 |
| --- | --- |
| `total_sample_count` | 分析时读取的原始存储记录总数 |
| `non_reduction_rows` | 状态不是 `REDUCING` 的记录 |
| `reduction_sample_count` | 状态为 `REDUCING` 的记录总数，包含基准称量 |
| `excluded_time_rows` | 记录 JSON 损坏、缺失，或 `stage_elapsed_s` 不能解析为数值 |
| `excluded_offline_rows` | 阶段时间存在，且质量标记包含“天平离线” |
| `excluded_other_quality_rows` | 阶段时间存在，存在其他质量标记，例如温度或 MFC 无效 |
| `excluded_value_rows` | 阶段时间存在且没有质量标记，但称量或还原度计算不成立 |
| `valid_sample_count` | 其余能形成有限还原度的原始还原段记录 |
| `valid_baseline_count` | 可用记录中 `sample_role=reduction_baseline` 的子集 |

按上述顺序归类，每条记录只归入一个主要原因。例如同一条记录既无阶段时间又标记天平离线，计入“缺少阶段时间排除”；既标记天平离线又标记温度无效，计入“天平离线排除”。

计数应满足：

- 总记录 = 非还原段记录 + 还原段记录。
- 还原段记录 = 可用称量点 + 四种排除原因。
- 基准称量点不大于可用称量点；它不参与气氛条件核查，但可以参与称量曲线。

自动插入的缺测断点、插值终点和人工曲线点均不计为原始采样。此处保留已有时间与质量筛选门槛；数量不能证明时间顺序、终点连续性、称量物理合理性或全过程完整性，这些仍由相应计算和过程证据表达。

## 人工补录、历史与报告

人工补录不增加采样数量。已有 `manual_used`、`input.manual_m1`、`input.manual_mt` / `manual_m180`、`input.manual_rate_points`、`input.source_record` 和 `rate_evidence` 继续保存计算来源；本次不为计数改写终点插值或增加来源推断。具备合法人工资料的计算可以显示零自动采样；不能因数量不足而否定已授权的人工补录。

计数与分析 JSON 一同保存到分析版本；后续重新分析产生新版本。单次报告读取该分析保存的计数，检验组报告读取组内冻结的分析 JSON，不从报告生成时的样本重新计算统计，不需要数据库迁移。

旧分析没有该字段，或摘要版本/结构不能识别时，显示“采样筛选统计：未记录”，不补零、不自动回写历史。浏览器旧模拟记录缺少原生阶段时间和质量记录，继续通过人工补录分析，其采样筛选统计保持“未记录”。

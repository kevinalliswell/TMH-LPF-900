# 05 领域规范

本文件按正式国标审查修订。原有“冷却目标加 5 ℃”“任意结束都通氮”“失重除含氧率与线性拟合”“逐颗膨胀指数取平均”等旧约定已废止。需求出处见 [国标核对](13-国标核对与首版需求.md)，阶段与人工操作见 [执行流程](16-国标阶段与人工确认.md)。

## 5.1 状态与启动

阶段状态为 `IDLE / CONFIGURING / RUNNING / STAGE_TRANSITION / COMPLETING / STOPPING / ERROR`。运行中包括阶段切换和结束保存；结束保存不能与下一实验、软件更新或删除记录重叠。

开始实验时校验已登录账户、实验权限、样品编号/名称、有限正初重、已启用程序，以及温度、天平和四路 MFC PV 的独立测量新鲜度。保护未复位或有待保存数据时拒绝启动。操作员和实际开始时间由后端生成。

初始状态等待第一个阶段的气氛回执，之后才进入运行。阶段气氛切换后同样等待回执再启动阶段计时。状态和原始样本使用实际经过时间，不能用固定 tick 次数替代真实时长。

## 5.2 标准与自定义程序

标准值以 `config/standard_programs.json` 为唯一代码来源。前端与原生共用表格，版本为 `GB-PROCEDURE-2026-09-08.1`。升温、连续恒温、固定还原以及各自正常结束步骤见 docs/16。

自定义实验应从标准模板调整温度和气氛条件，保留基础标准及本次实际程序快照。管理员编辑模式，保存于 SQLite；运行中不能修改已执行快照。自定义程序版本、差异追踪与完整限制仍在后续修复中，不能由自定义结果推定标准符合性。

## 5.3 推进与人工步骤

- 无效温度不是零温度；原生关键测量失效时保护停止。
- 升温按温度容差判达。连续恒温越界后重新计时。
- 还原和吹扫在确认气氛后按固定时长执行。还原温度偏离不自动延长暴露。
- 冷却严格小于方法规定的限值：低温粉化 100 ℃，自由膨胀 50 ℃，自由膨胀还须人工确认达到室温。
- 人工阶段不会因时间或温度自动结束。操作请求绑定实验和阶段；过期、重复或未收到气氛回执的确认拒绝执行。
- 只有升温、恒温、还原可带原因跳段；吹扫、人工确认、冷却不可跳过。跳段标记为实验偏离。

温度程序由仪表执行，上位机负责读数和有依据的参数修改。关炉、取管等动作由人操作并记录。当前模拟温度接口不是实际温控仪写入实现。

## 5.4 保护与保存

正常结束保留标准规定的末阶段气氛；停止、故障、恢复和应用退出请求固定保护气氛：N₂=5 L/min，H₂/CO₂/CO=0。保护锁存和优先队列阻断旧普通命令，显式复位作废旧命令代次。

H₂/CO 最终钳制位于 MFC actor 构帧前。保护动作尝试所有通道，不能因其中一路失败提前停止。界面和报告区分已确认正常结束与故障保护结果。

末批样本、结束时间、终态和幂等回执在同一事务提交。先写恢复日志，失败保留内存与文件，禁止新实验和退出，提供明确重试入口。详见 [数据恢复](15-数据保存与恢复.md)。

## 5.5 计算与报告

计算实现及测试位于 `crates/tmh-core/src/gb.rs`，版本 `GB-2026-09-05.1`：

- 13241：m₀ 为干试样质量，m₁/mₜ 为同一还原管与试样的称量，w₁/w₂ 为标准定义的亚铁含量和全铁质量百分数。`Rₜ = [0.111w₁/(0.430w₂) + 100(m₁−mₜ)/(m₀×0.430w₂)] × 100`。还原速率按 30% 与 60% 的交点时间差计算，系数为 33.6；未达到 60% 时按标准 55%/50% 分支计算，不做整段线性拟合。称量缺失允许带来源人工补录。
- 13242：分母 m₀ 为还原后、转鼓前质量；按筛上各级质量计算累计指数与差量细粉。转鼓与筛分条件需要外部操作记录。
- 13240：使用同一份 18 颗球团还原前后总体积，方法保持一致；`(V₁−V₀)/V₀×100`，不以逐颗百分数平均替代。

2—4 次独立试验的重复性选择已有核心计算，但组装、版本锁定和最终组报告仍待产品集成。当前报告是单次试验结果，不能自动出具材料合格或全过程标准符合结论。

原始遥测、质量码、阶段时间、分析输入/版本与人工补录保留历史。报告逐点检查已记录的还原温度、总流量及气体比例，不以均值代替逐点核查。模拟模式、缺测、跳段、外部步骤未核实和缺少重复组均须可见。

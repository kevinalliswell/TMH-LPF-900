# 05 领域规范(实验引擎、国标程序、安全不变式、GB 公式)

## 5.1 实验状态机(`tmh-core`,Rust enum + match)

阶段:`IDLE, CONFIGURING, RUNNING, STAGE_TRANSITION, COMPLETING, STOPPING, ERROR`

**合法转换表**(其余全部非法,返回 `InvalidTransition` 错误):

| From | To |
|---|---|
| IDLE | CONFIGURING |
| CONFIGURING | RUNNING, IDLE |
| RUNNING | STAGE_TRANSITION, COMPLETING, STOPPING, ERROR |
| STAGE_TRANSITION | RUNNING, COMPLETING, STOPPING, ERROR |
| COMPLETING | IDLE |
| STOPPING | IDLE |
| ERROR | IDLE |

状态快照字段:`phase, experiment_id, experiment_type_name, initial_weight, current_stage_index,
total_stages, stage_start_time, experiment_start_time, elapsed_seconds, error_message, params`。
`is_running = phase ∈ {RUNNING, STAGE_TRANSITION, COMPLETING}`。
每次转换发 `experiment-state-changed` 事件 + 写审计(EXPERIMENT 类别)。

## 5.2 实验参数(start_experiment 入参校验)

| 字段 | 规则 |
|---|---|
| sample_id(样品编号) | 必填非空 |
| sample_name(样品名称) | 必填非空 |
| sample_weight(样品重量 g) | 必填,float,**> 0** |
| operator(操作员) | 不接受前端输入；由当前登录用户的显示名生成快照 |
| experiment_type / mode_id | 必填,必须是已注册模式 |
| project_name / date / notes(备注) | **可选,允许为空** |

前置条件:三设备快照新鲜(last_ok_ts < 10s)——否则拒绝启动并给出具体离线设备;
状态机处于 IDLE;`initial_weight` 取自天平确认流程(见 docs/07 综合控制页)。

### 自定义模式

用户可创建同构的阶段序列(阶段类型 ∈ {HEATING, STABILIZING, REDUCING, COOLING},每阶段:
气体四路流量、目标温度、容差、时长、升温率、描述),持久化为 JSON(`config/experiment_modes.json`),
schema 同上表字段。标准模式与自定义模式统一为一个 `ProgramSource` 枚举,**禁止**两套分支代码
(旧版双分支曾产生"切回标准模式仍跑自定义程序"的缺陷)。

## 5.4 阶段推进规则(实验引擎,1s tick)

- 样品温度 = **T8**;温度读不到时按 0.0 处理(即不会误判达温)。
- 进入每个阶段时:按阶段气氛表**逐路下发**气体设定值(经安全钳制);记录 stage_start_time;
  发 `experiment-stage-info` 事件(此后每秒随 tick 发)。
- **判达条件**:
  - `duration > 0` 的阶段(恒温/还原):`|T8 − target| ≤ tolerance` **且** `elapsed ≥ duration×60s`;
  - `duration = 0` 且升温(HEATING):`|T8 − target| ≤ tolerance` 即判达;
  - `duration = 0` 且冷却(COOLING):**`T8 ≤ target + 5.0°C` 即判达**
    (⚠️ 新规格:旧版容差=0 导致冷却永不自动判达,是已知缺陷,此处为刻意修正);
- 判达 → 前进到下一阶段;末阶段判达 → 实验完成(COMPLETING → IDLE)。
- 操作员可**手动跳段**(带确认对话框,写审计)——用于断电/重启后与仪表进度重新对齐(旧 issue #19)。

## 5.5 安全不变式(硬性,代码评审重点)

1. **任何**实验结束路径(自动完成 / 手动停止 / 引擎错误 / 程序启动时发现上次异常退出)
   → 下发保护气氛:**N2=5.0,CO=0,CO2=0,H2=0**,并写审计。
2. H2/CO 设定钳制:唯一咽喉点在 MFC actor 构帧前(docs/03/04);0 恒放行。
3. `shutoff_flammable_gases` 命令在**任何状态**下可用(包括 ERROR、设备部分离线)。
4. 实验运行中禁止修改通讯配置(返回 `EXPERIMENT_RUNNING`)。
5. 审计写失败绝不向控制流抛错。

## 5.6 GB 国标计算(`tmh-core`,纯函数 + 单元测试)

### GB/T 13241 还原性

- 还原度:`Rt = ΔW / (W0 × (O2% / 100)) × 100`
  - `ΔW = W0 − Wt`(失重 g),`W0` 初始样重,`O2%` 为**百分数输入**(UI 默认 28.5,范围 0.01–100)。
  - 金值:W0=100, Wt=85, O2=30 → **Rt = 50.0%**(⚠️ 旧版曾把百分数当分数用,错 100 倍——此公式为修正后)。
- 还原速率指数:对 (t_min, Rt) 序列做**一次线性拟合**,斜率即指数(%/min,保留 3 位)。
- 条件校验(报告用,不阻断):温度均值 900±10℃ 且标准差 ≤5;总流量 15±0.5 L/min;时长 ≥180min。

### GB/T 13242 低温粉化 RDI

输入四个筛分质量(g):`m_gt6.3, m_3.15~6.3, m_0.5~3.15, m_lt0.5`,初始样重 `m0`:
- `RDI+6.3 = m_gt6.3 / m0 × 100`
- `RDI+3.15 = (m_gt6.3 + m_3.15~6.3) / m0 × 100`(累计)
- `RDI−0.5 = m_lt0.5 / m0 × 100`
校验:筛后总质量与 m0 差值过大(>2%)时报告警示。

### GB/T 13240 自由膨胀指数

每球团:`SI = (V1 − V0) / V0 × 100`(V0/V1 为还原前/后排水法体积 mL);多球团取平均;
报告含逐球团明细与平均值。

全部计算结果连同输入参数序列化 JSON 存入 `experiments.analysis_results_json`(docs/06)。

# 检验组与数值修约

依据 docs/13 §4 及用户提供的三项正式标准 PDF。以下作为本轮实现契约，界面接入和发布验收完成前不表示已有整组交付能力。

## 结果计算

还原性按材料类型选择 A/B/C：烧结矿 5/6/6.6，球团矿 3/3.6/3.9；天然块矿须录入供需双方商定限值与依据。低温粉化按 RDI+3.15 决策，其表 1 中间平均值的取档规则尚未确认，首版要求人工录入本次检验限值与来源，不推测插值。自由膨胀采用 3/3.6/3.9 和逐次 2→3→4 规则。

保存单次计算的未修约数值。低温粉化按 §9.1 先得到一位小数的单次试验结果用于 §9.2 的比较和平均，另外两项参考指标随主指标采用相同试验集合。还原性和自由膨胀直接采用未修约单次计算值作重复性判断，再对所选结果平均值一次修约；RVI 取与 RI 相同的试验集合，缺少任一采用试验的 RVI 时标为缺失，不改用其他试验凑数。

最终主指标及 RDI 参考指标保留一位小数，RVI 保留两位。按 GB/T 8170 §3.2、§3.3 实施半偶修约和一次修约：舍弃部分恰为一半时按保留末位的奇偶决定，负值对绝对值修约后恢复符号。使用已保存浮点值的最短往返十进制表示作精确求和、平均及极差比较，避免额外的二进制求和或相减误差改变十进制边界；不使用 epsilon 扩大国标限值。此数值表示方案是软件实现选择，不消除原始测量不确定度。

修约条文来源：[GB/T 8170-2008 标准文本](https://cugp.cug.edu.cn/cbsold/GBT81702008.pdf) §3.2—3.3；[生态环境部 HJ 706-2014](https://www.mee.gov.cn/ywgz/fgbz/bz/bzwb/jcffbz/201411/W020141209397243204063.pdf) §8 对进舍规则的引用可交叉核对。标准现行状态见[国家标准公开平台](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=7C962A3A9554F626A9305C24B36E6DA6)。

## 组记录与报告

检验组记录试样批次、材料类别、同批独立试验确认、阈值及来源、实际创建人、时间和修改原因。后端从用户有权访问的实验读取数据，按实际开始时间确定先后，拒绝重复实验编号、混合方法、不同温度/气氛制度和不同数据来源。

每次保存固定当时单次分析结果、分析版本、程序及运行/报告元数据。后续重新分析或修改单次报告不会改写已有组版本；补测产生新版本并沿用已固定的成员数据。无效试验的人工排除须填写原因，标准算法自动去极值也记录采用和剔除的具体试验编号。

不足所需次数时允许保存待补测的组记录，不出具最终数值。一次决策已完成后不能再混入多余有效试验。模拟数据、自定义条件、过程验证状态、数据完整性、重复性计算结论分别显示；不能把重复性计算完成等同于国标方法符合或采购质量合格。

真实设备、通道映射、校准资料及全过程核查仍有独立验证要求。

## 存储接入

SQLite v8 新增只追加的检验组版本表，当前视图读取最大版本，不覆盖旧快照。版本号采用并发比较，陈旧保存拒绝写入；组归属不能通过追加版本改变，实际录入者单独记录。列表和历史分批读取，每页最多 25 条。单个组快照限制 1 MiB。

单次分析版本采用实际数据库记录编号，单独补录报告资料不冒充一次重新计算。组快照独立于原实验行，删除单次记录不会级联删掉已保存的组证据。原生访问边界与界面操作见下节。

## 冻结证据与报告

组检只接收试验编号、材料、批次确认、必要的限值依据、排除原因和报告补录资料。计算输入由服务端读取单次分析版本、执行程序与运行记录；正常完成、完整落盘、没有跳段且制度及来源一致的记录才能参与重复性决策。成员一经保存，后续版本保留原始证据；修订报告信息或排除原因形成新的组版本，不覆盖旧版。

重复性顺序以绝对开始时间为准：优先使用运行记录的 `started_at_utc`，兼容有时区的 RFC3339 开始时间。无时区旧记录不能按电脑当前时区猜测，不能作为有效重复试验；带原因人工排除时仍保留原始证据。无法确认时间的排除记录列在末尾，不参与判定。

组报告完全读取指定版本快照，包括采用集合、人工排除和去极值原因、计算与修约版本，以及六项人工报告资料：实验室、地址、报告编号、日期、复核人、偏离说明。输出的 HTML 可离线打开并打印为 PDF；完整证据可展开阅读。模拟/回放数据显著标识，数值重复性决策不等同于全过程方法符合性或采购性能合格性。

## 桌面命令与访问范围

预览、保存、分批列表、指定版本读取和报告导出均要求有效会话。普通用户仅访问自己的组；管理员可以复核其他用户的组，但追加成员同时验证组归属者的读取权限，避免借编辑组将他人数据隐式分享。管理员自己创建的组可汇集有权读取的试验。

保存和预览在同一数据库锁内读取全部权威证据；保存比较上一版本后只追加新版。导出保存独立 HTML 与同名 JSON 证据文件到当前用户导出目录，记录实际操作者及指定组版本。新实验另外记录 UTC 开始时间，历史列表使用的本地显示时间保持原有格式。

浏览器预览不具备原生实验数据库，组检命令会明确要求使用桌面应用，不生成模拟的检验结论。桌面模拟设备仍可经过真实数据库、分析、组检和报告完整链路，用于软件验证。

## 检验组界面

主导航「检验组报告」提供建组、材料与人工限值依据、独立试验选择、排除原因、报告资料补录、预览、追加版本和指定版本导出。新组可以先保存待补测状态；已有组保留成员证据，历史版本只读，最新版本允许补充试验或修订资料。表单更改会清除旧预览，未保存时不能导出或切换页面；保存或撤销后恢复导航。锁定和退出账户不受页面编辑保护拦截。

界面不重新计算科学结果，显示 Rust 返回的决策、采用集合和修约字符串。离线组报告和 JSON 证据由桌面命令生成。浏览器测试使用独立模拟证据桩验证界面，不能替代原生窗口与实际设备验收。
